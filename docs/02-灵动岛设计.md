# 灵动岛设计 v1.0（已冻结）

> 命名口径：用户口中的"个人信息页面（工作台）"在本文档定名为 **工作台**；第 4 页定名为 **个人中心**（资料/设置），避免歧义。
> 灵动岛与后续完整 OA 客户端共用同一 FastAPI 后端与 `docs/01-数据库与接口契约.md`。

## 一、设计原则

1. **不挡事**：胶囊态只占顶部一条 36px；用户不看它时它不存在（视觉+交互上都极轻）
2. **一秒可达**：任何常用功能（发消息、勾待办、审批）≤2 次点击
3. **状态即窗口**：胶囊/展开两种窗口尺寸，不用点击穿透 hack

## 二、窗口模型与状态机

| | 胶囊态 | 展开态 |
| --- | --- | --- |
| 尺寸 | 216 × 36（物理像素，DPI 缩放前） | 1280 × 480 |
| 圆角 | 18（全胶囊） | 20 |
| 内容 | 时间 · 正在播放曲名(跑马灯) · 未读角标 | 页签栏 + 4 页面内容 |
| 位置 | 默认主屏顶部居中，可拖动，位置持久化 | 以胶囊 x 为中心向两侧展开并向下（clamp 屏幕边界） |

```text
状态机：
collapsed --点击胶囊 / 全局热键(P1)--> expanded
expanded  --Esc / 点击窗外(Window deactivated) / 收起按钮--> collapsed
首次启动（无 token）--> 强制展开，仅显示登录卡（无页签）
```

窗口属性（全程不变）：无边框、透明背景、`AppWindow` 置顶（`AlwaysOnTop`）、跳过任务栏、不出现在 Alt+Tab（`IsShownInSwitchers=false`）。

**实现要点**：

- 两态切换 = `DispatcherTimer` 60fps 缓动逐帧 `AppWindow.Resize`（约 220ms，ease-out cubic，13 帧）；内容区用 Composition 做 scale 0.92→1 + 淡入，圆角在 code-behind 同步插值
- 拖动：胶囊态监听 PointerPressed/Moved，换算 `AppWindow.Move`；持久化到 LocalSettings
- 多显示器/DPI：`DisplayArea.GetFromPoint` 取工作区，坐标用物理像素计算，边界 clamp
- 托盘图标（右键：展开/收起、开机自启开关、退出）+ 单实例互斥
- 独占全屏应用会盖住岛：接受，不抢 z-order

## 三、展开态整体布局

```text
┌──────────────────────────────────────────────────────────┐ 1280px
│ [🕘工作台] [📁文件] [💬对话] [👤我]               ●●● [—] │ 44px 页签栏（选中指示条滑动，[—]=收起）
├──────────────────────────────────────────────────────────┤
│                  页面内容区 ≈ 1256 × 424                  │
└──────────────────────────────────────────────────────────┘
```

背景：Mica（深浅色跟随系统）；内容卡片 Acrylic 半透明。页签切换：内容横移 + 淡入（200ms）。

## 四、页面设计

### P1 工作台（小组件仪表盘）

**自由布局系统**：用户可增删/排序小组件，布局存 `LocalSettings` JSON（仅本机，不与服务端同步——换机重新配，v1 接受）：

```json
{"widgets":[{"type":"weather","span":"wide"},{"type":"todo","span":"wide"},
            {"type":"launch","span":"small"},{"type":"approval","span":"small"},
            {"type":"photo","span":"wide"},{"type":"music","span":"wide"}]}
```

内容区自适应 6 列网格（`WrapPanel` 思路）：`small` = 1 格（约 199×124），`wide` = 2 格（约 410×124），同屏可见 3 行、超出滚动。右上"+"按钮弹出小组件目录 Flyout 添加；每个组件右上悬浮"×"删除、长按拖动排序。

**小组件目录（P0 共 6 个）**：

| 组件 | 尺寸 | 数据源 | 交互 |
| --- | --- | --- | --- |
| 天气 | wide | Open-Meteo 直连（城市=设置里的 lat/lon） | 显示今明两天；点击展开 7 天浮层 |
| 待办 | wide | `GET/POST /todos` | 未完成前 5 条，勾选即 `PUT done`；顶部快速添加框 |
| 喜欢的照片 | wide | `GET /favorites`（收藏的图片文件） | 轮播 5s/张；点击全屏查看浮层 |
| 音乐 | wide | SMTC `GlobalSystemMediaTransportControlsSessionManager` | 封面+歌名+歌手；⏮ ⏯ ⏭ 控制当前系统播放器 |
| 客户端启动 | small | LocalSettings（用户配路径，最多 4 个） | 图标矩阵点击启动（`Launcher`） |
| 审批入口 | small | `GET /approvals?box=todo` 计数 | 显示"待审批 N"；点击浮出审批列表/详情层 |

胶囊态的"正在播放"与音乐组件同源；审批角标与审批组件同源。

### P2 文件页（左右分栏）

```text
┌──────────────┬──────────────────┐
│ 公共文件      │ 我的文件          │
│ [全员公共 ▼]  │ [↑上传]          │
│ ├ a.doc      │ ├ b.png  [★]     │
│ ├ c.xlsx     │ ├ c.pdf          │
│ …            │ …                │
└──────────────┴──────────────────┘
     45%              55%
```

- 左侧顶部**群选择栏**（ComboBox）：`全员公共` + 我所在的群（数据来自 `GET /conversations` 中 type=group 的项）
- 左 = 选中群/全员的公共区，右 = 个人文件；各自列表：文件名/大小/时间，行内操作（下载/删除/收藏仅图片）
- 上传：右栏"↑上传"（个人区）；公共区上传 = 群主/admin（左栏长按/右键出现上传入口）
- 下载弹 `FileSavePicker`；上传弹 `FileOpenPicker` 多选
- P0 平铺列表（`folder` 列已预留，目录树 P1）
- 权限：全员区——全员读 admin 写；群区——群成员读、群主+admin 写；个人区——仅自己

### P3 对话页（左列表右会话）

```text
┌──────────┬────────────────────┐
│ 会话列表  │ 对方/群名           │
│ [🔍]     │ ┌ 消息气泡区(滚动) ┐ │
│ ● 张三 2  │ │                  │ │
│   群:XX 5 │ └──────────────────┘ │
│   李四    │ [输入框        发送] │
└──────────┴────────────────────┘
   260px           其余(约988px)
```

- 列表项：头像+名称+最后一条摘要+未读数；进入会话即 `PUT /read`
- 新发起：列表顶部🔍 → 通讯录（`GET /departments` 选人单聊 / 多选建群）
- 消息类型：文字 / 图片（`scope=chat` 文件）/ 文件（复用文件上传）
- 实时性：WS `message.new` 追加气泡 + 更新列表摘要 + 未读角标
- 图片点击放大浮层；文件点击下载

### P4 个人中心

左右双栏：左栏 = 资料（头像点击换 multipart 上传、姓名、部门、角色）；右栏 = 设置组：

- 常用软件（最多 4 个：路径+名称，自动提取 exe 图标）
- 天气城市（搜索选点，存 lat/lon/城市名）
- 开机自启开关、服务端地址（首次配置）、退出登录、修改密码
- token 存 `PasswordVault`（Windows 凭据管理器），不落明文

### 登录卡（首次/登出后）

展开态中央 280×320 卡片：logo + 用户名/密码 + 登录按钮 → `POST /auth/login`，成功后进入工作台。服务器地址未配置时先提示填写。

## 五、审批浮层（非页签）

从工作台审批组件或胶囊角标进入：在展开态内容区覆盖一层，宽屏下左右双栏——左 = 列表（待我审批/我已审/我发起 三个 segment），右 = 详情（表单 JSON 渲染 + 时间线 + 通过/驳回按钮 + 意见框）。Esc 返回上层页面。

## 六、客户端工程结构（规划）

```text
client/  (VS2022, WinUI3 C++/WinRT, Windows App SDK 1.5+)
├─ App.xaml / IslandWindow.h/.cpp     # 壳：两态切换/拖动/动画/托盘
├─ Pages/  Workbench Files Chat Me Login Approval(浮层)
├─ Widgets/ IWidget.h + 6 个组件 + WidgetCatalog(注册表)
├─ Services/ ApiClient(Windows.Web.Http) WsClient(MessageWebSocket)
│            SmtcService SettingsStore(LocalSettings) Vault(PasswordVault)
└─ Controls/ SegmentedTabs AnimatedResizer
```

## 七、契约变更（已同步 01 文档）

1. `files` 表新增 `group_id`（可空，指向 type=group 的 conversation）：NULL=全员公共区，非空=群公共区
2. `GET /files`、`POST /files/upload` 增加 `group_id` 参数
3. 群公共区权限：群成员读、群主+admin 写

## 八、已拍板决策记录（v1.0 冻结）

1. 群公共区**写权限 = 全体群成员可写**（admin 同样可写；非成员不可见）
2. 客户端形态 = **完整桌面 OA 端**（承载全功能+管理后台；技术栈默认同 WinUI3，开工前可再议）
3. 展开态尺寸 = **1280×480**（横向宽板），胶囊态 216×36 不变
