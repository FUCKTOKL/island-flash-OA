# island_four — 天平账 BALANCE LEDGER（唯一保留 · 全账本版）

一个 `secrets` 随机字符串（≤25 字符）驱动的设计基因，**字符串不出现在 UI 中**：
`P^:Uo$(wXhkA=7RDd:` → `= $ ( ) :` 账本等式/借贷符号 → **天平账**。

## 结构

- **胶囊 = 支点**：岛向左右**张翼**展开（scaleX，非向下）
- **天平梁**：双翼顶横梁 + 两端青蓝配重点
- **四账页导航**：账本索引页签（第一章·台账 / 第二章·凭证 / 第三章·往来 / 第四章·名册）
- **审批对账浮层**：拍板"审批不开页签"，从台账贷方卡"对账 ›"呼出

## 账页与功能（island-3.html 单文件可玩）

| 账页 | 左翼（借方） | 中央天平柱 | 右翼（贷方） |
| --- | --- | --- | --- |
| 第一章·台账 | 待办账目行（点击勾销 ✓=结 / 回车入账） | 天气大数字+活体时钟 | 审批 hero（烟熏石板+冷粉计数）+ 对话速览 |
| 第二章·凭证 | 公共账本（群 chips 切换 / 行选中） | 凭证详情（类型大字+下载/收藏） | 我的账本（★收藏/取/销 / 上传存入） |
| 第三章·往来 | 往来户头（头像+摘要+未读余额徽标） | 对方名片（头像+部门+在线） | 往来流水（回车拍发，未读清零） |
| 第四章·名册 | 我的档案（姓名/部门/职位/工号） | 本人名片 | 设置章程（服务端/天气城市/自启/穿透/**暗夜账本主题真生效**）+ 密钥更换 |

**审批对账浮层**：顺序链可视化（节点①→② 已过=青蓝✓ / 当前=冷粉发光 / 未启=灰），
批准=过账链前移、驳=退票移除；台账 hero 计数与胶囊徽标实时联动；清零显示"账目两清 = 0"。

## 技术

- 自包含单 HTML，v3.2 冷玻璃语言（冰白×石板×青蓝 #4FA3A5×覆盆子 #C74E5C×毛玻璃 + 暗夜模式 CSS 变量）
- 全 DOM 构建（createElement/textContent，零 innerHTML）
- 点胶囊重播张翼动画；Esc 关浮层

## 移植注记（→ WinUI3）

张翼展开 = 以胶囊 x 为锚的双侧 Resize 动画（现有 Expand 动画链改造）；
账页 = 左右两列+中央柱 Grid；对账浮层 = ContentDialog/Popup。
