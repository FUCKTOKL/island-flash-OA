# island_four — 四个随机字符串驱动的独立「岛结构」设计

四个 `secrets` 加密级随机字符串（任何可打印字符，长度 12-25）。
**字符串不出现在任何 UI 中**，仅作为灵感触发器记录于此。
全部设计以**单元矩阵 v3.2**（冰白×冷石板×青蓝 #4FA3A5×覆盆子 #C74E5C×毛玻璃）为语言基底，
探索的是**岛本身的结构与展开方式**（非页面布局）。

| # | 随机字符串 | 灵感基因 | 岛结构方向 | 文件 |
| --- | --- | --- | --- | --- |
| 1 | `4os\7A&FDbO<CI7%4*f\|\5{Hj` | `\ \| <` 斜线交织、管线分流 | **斜谷 SLASH VALLEY**：岛体=平行四边形斜切大玻璃（顶边左移），内容整体 -4.5° 斜置，每张浮片自身斜切（clip-path 14px），全屏零垂直分割线 | island-1.html |
| 2 | `t{{{@Qw^0Q+R-=b[Z-/YY}` | 三重 `{{{` 级联、`}` 收束、瀑布 | **三叠湖 CASCADE**：胶囊向下长出三层错位玻璃板（760→1020→1280 递宽、逐层左移、stagger 下落），模块住在不同深度层级（L1 天气+时钟 / L2 任务流+审批 / L3 对话+文件+媒体） | island-2.html |
| 3 | `P^:Uo$(wXhkA=7RDd:` | `= $ ( ) :` 账本等式、借贷 | **天平账 BALANCE LEDGER**：胶囊=支点，岛**向左右张翼展开**（scaleX，非向下）；左翼=待办借方（账目行 ✓=结）/ 右翼=审批贷方（¥金额）+ 对话往来；中央天平柱=天气大数字 | island-3.html |
| 4 | `-[w\&!vLv6#C` | 极短破折、尖锐收束、极简 | **破折刃 DASH BLADE**：反仪表盘——展开态只是一条 104px 细刃（scaleX 从胶囊横向长出），5 个等宽分段=模块摘要；悬停分段向下抽出毛玻璃浮片详情（渐进披露）；刃两端青蓝刻度线 | island-4.html |

## 查看

双击任一 HTML 在浏览器打开（自包含）。每个都含展开动画，**点胶囊可重播**：

- 岛一：整体斜切长出，浮片斜向滑入
- 岛二：三层板 stagger 瀑布下落
- 岛三：双翼从中心向两侧张开
- 岛四：细刃横向延展，悬停各分段看抽出浮片
